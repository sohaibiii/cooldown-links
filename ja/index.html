On Iceのしくみ

On Iceは、あなたと購入ボタンのあいだにひと晩を置きます。

つい買ってしまうショッピングアプリとWebサイトを、あなたが選びます。そのあとは、どれかを開いてもまっすぐ購入手続きへは進みません——まずOn Iceのブロック画面が現れます。買う前にひと呼吸。メモするをタップしてそれを書き留めるか、やめておくをタップして見送ります。あなたに代わって何かが購入されたり、キャンセルされたりすることはありません。

書き留めたものは、リストで待ちます——別の長さを選ばないかぎり、24時間です。待ち時間が終わると、On Iceはひとつだけ尋ねます。「まだ欲しいですか？」たいていの「欲しい」はひと晩を越えられず、越えたものは本物です。どちらの答えも、よい答えです。

  • 保護アプリのホーム画面にスイッチがひとつ、そしてショップごとにひとつずつ。オンのあいだ、選んだショップは開くかわりにOn Iceのブロック画面を表示します——アプリもWebサイトも、Safariのなかでも。
  • 短いひと呼吸何よりも先に、ひと息つく、一文を入力する、リマインダーを読む、あるいは何をしに来たのかを言う——そのためのひととき。どれにするか、どれくらいの長さにするかは、あなたが選びます。
  • メモするほしい物の名前を書き、だいたいの価格をタップし、いまの気持ちをタップします——退屈、ストレス、お祝い、買い逃したくない、または「必要なもの」。1画面、15秒です。
  • 保留中メモしたアイテムは、カウントダウンのリングの下で待ちます。アイテムがクールダウンしているあいだ、何かが購入されることはありません。どうしても今ショップが必要なら、数分間だけ開き、そのあとブロック画面はひとりでに戻ってきます。
  • 推定節約額手放したアイテムはすべて累計に加わります。累計は、すべてあなた自身が入力した価格からできています——今日、今週、今月の分を。
  • 目標、上限、ブロック1日のショッピング時間の目標、1日の上限、時間指定ブロック、集中モードのブロック、そしてうまくいかない時間帯のためのルール。厳格モードが、あなたの設定をそのまま保ちます。
  • ほかにできること自分だけの日記と、代わりにすることをいくつか——散歩、本、電話——買いたい衝動に行き場が必要なときのために。
  • ウィジェット、ライブアクティビティ、ショートカットホーム画面とロック画面に推定節約額と保留中のもの、ショップが開いているあいだのカウントダウン、そしてブロックを始めるためのSiriとショートカットのアクション。

動作条件

デバイスiOS 17以降を搭載したiPhoneまたはiPad。一部の追加機能にはそれ以上が必要です。コントロールセンターのコントロールにはiOS 18が、Apple Intelligenceによる作成には対応するデバイスと言語が必要です。
許可スクリーンタイムへのアクセス。セットアップ中に一度だけ、Apple自身の確認画面で許可します。On IceはAppleのスクリーンタイムのフレームワーク——iOSに内蔵されたApp使用時間の制限と同じしくみ——を使っており、ショップの前に実際に立っているのはOn IceではなくAppleです。
アカウント不要です。アプリのどこにも、登録も、メールアドレスの入力欄も、パスワードもありません。
インターネット不要です。ブロック画面も、ひと呼吸も、リストも、タイマーも、合計も、すべてオフラインで動きます。ネットワーク通信が発生するのは、Premiumを購入・復元するときのApple自身の通信と——あなたがオンにして作成元にOpenAIを選んだ場合の——任意のAIリフレクションだけです。
言語English、Deutsch、Español、Français、日本語、한국어、Português (Brasil)、简体中文。On Iceはデバイスの言語に従いますが、設定 → 言語で選んだ言語にすることもできます。
任意通知：デバイス上で作られ、ブロック画面からアプリへあなたを受け渡すためと、アイテムの待ち時間が終わったことを知らせるために使います。モーションとフィットネス：散歩中の歩数をリアルタイムで表示するためだけに使います。Face IDまたはTouch ID：日記をロックする場合にだけ使います。

はじめかた

セットアップはほんの数画面で、終わるころには保護がもうオンになっています。

  1. 10秒のひと呼吸を試します——あとでブロック画面がくれるのと同じひとときです。
  2. Appleが尋ねたらスクリーンタイムへのアクセスを許可します。これがないとOn Iceは動けません。設定 → スクリーンタイムでいつでも取り消せます。
  3. Appleの選択画面でショップを選び、ブロックしたいショッピングサイトを追加します。On Iceが、あなたの選んだアプリの名前を知ることはありません——プライバシーをご覧ください。
  4. 必要なら危ない時間帯を設定します——買い物がうまくいかなくなる、夜遅くの時間です。任意で、あとから変更できます。
  5. 完了です。ショップのどれかを開いて、ブロック画面に出会ってください。
最初のブロック画面は唐突に感じるかもしれません。でも、それこそがこのアプリの出番です——メモするをタップして、15秒だけ使ってください。

節約額の数字について

On Iceの価格はすべてあなた自身が入力したもので、アプリが表示するお金の数字にはすべて推定と記されています。これはあとから付け足した注意書きではありません——設計そのものです。

  • On Iceは銀行に接続せず、購入履歴を読まず、実際の値段を確かめず、通貨の換算もしません。
  • アイテムが累計に加わるのは一度だけ、待ち時間のあとであなたがそれを手放したときです。
  • アイテムに戻ってこなかった場合は、On Iceがお知らせし、待ち時間が終わってから48時間後に、そのアイテムを手放したものとして数えます。それまでは、いつでも決められます。
  • キープしたアイテムは累計に影響しません——ただし、見積もりより安く買えたとあとでOn Iceに伝えた場合は、その差額が加算されます。
  • 支出記録は、On Iceが見ていない衝動買いのためのものです。節約額とは分けて記録されます。
この数字は、買わないと決めたものの記録で、価格はあなたが見積もったものです。誇りに思ってよい数字であり、スプレッドシートに入れるには向かない数字です。

よくある質問

On Iceは無料ですか？
はい。無料版はお試しではなく、ちゃんと使える製品です。ショッピングアプリ1つとWebサイト1つのブロック、24時間の待ち時間とリスト、推定節約額、深呼吸のひと呼吸、代わりにすること3つ、日記、1日のショッピング時間の目標、そして時間指定ブロックと集中モードのブロック。
Premiumで何が増えますか？
ブロックしたいショップとWebサイトのすべて。12・24・48・72時間の待ち時間。あらゆる種類のひと呼吸、繰り返し開こうとするほど長くなるひと呼吸、そして自分のリマインダー。危ない時間帯とショップ別のルール、1日の上限、厳格モード、あなたの買い物パターンと買ったあとの気持ち、日記のふり返り、代わりにすること6つ、ウィジェット、そして任意のAIリフレクション。Premiumは月額または年額のサブスクリプション——年額は、提供される場合は無料トライアルから始まります——か、一度きりの買い切りで、年額と買い切りにはファミリープランもあります。価格はお住まいの国向けにアプリ内に表示され、請求はAppleが扱います。
ファミリープランはどのようなしくみですか？
Premium ファミリー年額プランとPremium ファミリー買い切りは、Appleのファミリー共有を通じて、ファミリーグループのほかの最大5人と共有されます——合わせて6人です。それぞれが自分のデバイスの自分のOn IceでPremiumを使えます。ほかの人のショップ、リスト、日記、節約額を、誰かが見ることはありません。
買い物ができなくなるのですか？
いいえ。ふつうのブロック画面はひと呼吸であって、壁ではありません。メモするをタップして目に留まったものを書けば、今すぐ買い物をしたいでショップが数分間開きます。もう十分——またブロックするで早めに閉じることもできます。通り抜ける道がないのは、あなた自身が設定したものだけです——完全ブロックのルール、すでに達した1日の上限、時間指定ブロック、集中モードのブロック——そして、そのどれもがひとりでに終わります。
サブスクリプションが切れたらどうなりますか？
あなたが築いたものは何ひとつ取り上げられません。リスト、履歴、推定節約額は残り、選んだショップはブロックされたまま、ルール、上限、実行中の厳格モードも効き続けます。待ち時間は24時間に戻り、AIリフレクションはオフになり、ウィジェットとパターンの画面はPremiumが戻るまでお休みします。できなくなるのは、Premiumの機能をさらに加えることだけです。
新しいデバイスで購入を復元できますか？
はい。設定を開いて購入を復元をタップしてください。PremiumはデバイスではなくあなたのAppleアカウントに属しています。リスト、日記、履歴は一緒には移りません——それらは作られたデバイスにあり、新しいデバイスへはデバイス全体のバックアップによってのみ移ります。
iPadでも使えますか？
はい——iOS 17以降のiPhoneとiPadで使えます。デバイスごとにショップ、リスト、履歴を別々に持ち、デバイス間で同期されるものはありません。
On Iceは、なぜどのアプリを保護したか教えてくれないのですか？
本当に知らないからです。Appleのスクリーンタイムは、あなたのデバイスの外では意味を持たない不透明なトークンをOn Iceに渡します——アプリ名も、識別子もありません。On IceはiOSにそれらのブロックを頼むことができ、名前とアイコンはiOSが描いてくれますが、On Iceにはそれを読むことができません。例外は、アドレスを入力して追加したWebサイトです。iOSがそれをブロックできるよう、On Iceはそのアドレスをデバイスに保存します。
ブロックできるのはアプリだけですか？Webサイトもですか？
両方です。ショップのアプリとWebサイトを別々に追加すれば、それぞれがブロックされます——WebサイトはSafariで。
On Iceは、私が買うものを見ていますか？
いいえ。銀行にも、注文にも、閲覧にも、カードにもアクセスできません。記録するのは自分自身の出来事だけ——ブロック画面が表示されたこと、そしてあなたが何を選んだか——で、それもデバイスに残ります。
日記がデバイスから出ることはありますか？
けっしてありません。私たちにも、OpenAIにも、どんな設定でも。Face ID、Touch ID、またはパスコードでロックでき、任意の1週間の要約は、デバイス上のApple Intelligenceが書きます。
歩数はどこへ行きますか？
どこへも行きません。散歩中、On Iceは歩数をリアルタイムで表示し、散歩が終わると忘れます。Appleの「ヘルスケア」から読むことも、書き込むこともありません。
AIリフレクションとは何ですか。オンになっていますか？
選択肢の前にときどき届く短い問いかけひとつと、日曜日に届く1週間についての数文です。あなたがオンにするまではオフです。誰が書くかは、あなたが選びます：デバイス上のApple Intelligenceか、OpenAIか——後者は、アプリのなかでデバイスの外へ何かを送る唯一のものです。何が送られるかは、プライバシーポリシーに正確に記載しています。

うまくいかないとき

ショップがブロック画面なしで開いてしまう

  • アプリのホーム画面の上部で保護がオンになっているか、そしてそのショップ自身のスイッチがオンになっているか確かめてください。
  • スクリーンタイムへのアクセスがまだ許可されているか確かめてください：設定 → スクリーンタイム → スクリーンタイムにアクセスできるApp。取り消されていた場合、On Iceは、もう一度お願いするための画面を表示します。
  • あなたが開いた買い物タイムがまだ続いているのかもしれません。ひとりでに閉じます——またはもう十分——またブロックするをタップしてください——そうすれば、ブロック画面が戻ります。
  • そのショップがルールでしかカバーされていない場合、ブロック画面はそのルールの時間帯にだけ現れます。
  • それでもだめなら、設定 → 保護ツール → 保護を修復で、すべてのブロックとスケジュールが適用し直されます。

「メモする」をタップしてもOn Iceが開かない

  • iOSのバージョンによっては、ブロック画面は通知を通じてあなたをアプリへ受け渡します。通知がオフだと、iOSはそれを届けられません——設定 → 通知 → On Iceでオンにしてください。
  • On Iceを自分で開いても、メモを待っているアイテムが引き継がれます。

Webサイトがブロックされない

Webサイトはアドレスでブロックされます。追加したアドレスが、実際に開くアドレスと一致しているか確かめてください。また、ショップのアプリとWebサイトは、別々に追加する2つのものであることを覚えておいてください。

1日の目標や上限の分数が、思ったより少ない

iOSは、ほかのアプリでどれだけ時間を過ごしたかをアプリに教えません。On Iceに伝えるのは、保護しているショップでの時間がひとつの段階を越えたことだけです——はじめは5分ごと——そのためOn Iceは「少なくとも」その分数を表示します。実際の数字は、もう少し多いことがあります。

保護をオフにできない、またはショップを削除できない

厳格モード、時間指定ブロック、集中モードのブロックのどれかが動いていないか確かめてください——アプリのホーム画面に表示されます。厳格モードが動いているあいだは、設計上、設定がそのまま保たれ、あなたが選んだ時刻にひとりでに終わります。誰かがキーを預かるを設定していれば、PINを持っている人が早めに終わらせることができます。

AIの問いかけがまったく表示されない

Premiumが必要で、設定 → AIリフレクションでオンにするまではオフです。オンにしても、問いかけるのは理由があるときだけです——あなたがよく後悔してきた気持ち、危ない時間帯、あるいは高めの価格。作成元がOpenAIの場合は、インターネット接続が必要です。何かがうまくいかなければ、代わりにふつうの選択肢が静かに表示されます。

ウィジェットが古いまま

iOSは独自のタイミングでウィジェットを更新します。On Iceを開けば最新になります。節約額と「保留中」のウィジェットは、Premiumに含まれます。

Premiumが認識されない

設定で購入を復元をタップし、購入したときと同じAppleアカウントでデバイスにサインインしているか確かめてください——ファミリープランの場合は、購入者のファミリー共有グループに入っているかどうかも。返金や請求のご質問は、Appleサポートを通じてAppleが扱います。

アプリの言語が違う

設定 → 言語で選んでください。Apple自身のアプリ選択画面は、次にOn Iceを開いたときから切り替わります。
